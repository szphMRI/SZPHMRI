# 一种分析报告的生成方法、装置及可读存储介质





## 1.系统概括

### 1.1 项目定位

>本系统是基于``磁共振检测系统(MRI)``的分析报告的生成，旨在解决现有医院信息管理系统自动化生成分析报告中存在的临床可信度、准确性和全面性不足的问题。
>
>

### 1.2核心流程

>本项目是基于专利文件**一种分析报告的生成方法、装置及可读存储介质**，主要用于首先获取患者的磁共振影像数据，并根据磁共振影像数据确定患者的病灶信息；其次，通过检索增强生成算法根据病灶信息生成病灶检索数据，并根据病灶检索数据对医学知识库执行关键词检索和语义向量检索，得到循证检索结果，根据循证检索结果进行可信度筛选，得到循证证据信息；然后，根据所述循证证据信息和所述病灶信息进行诊断，得到分析结果；其中，分析结果包括病灶类型、病灶状态评估和病灶诊断依据；最后，根据分析结果生成患者的分析报告，向医生的终端设备发送分析报告。实现了自动化生成的分析报告的准确性、可信度和全面性的提升。
>

```
│   │   ├── __init__.py
│   │   └── pipeline.py         # 主流程编排
│   ├── services/
│   │   ├── __init__.py
│   │   ├── imaging.py          # MRI 影像读取/预处理（pydicom）

│   │   │   ├── retriever.py       # 关键词+向量混合检索
│   │   │   ├── reranker.py        # 可信度筛选/重排
│   │   │   └── index.py           # 知识库索引（BM25+向量）
│   │   ├── analyzer.py         # 分析推理（病灶类型/状态/依据）
│   │   ├── report.py           # 报告生成
│   │   └── notifier.py         # 推送到医生终端
│   ├── models/                 # 数据模型/接口抽象
│   │   ├── __init__.py
│   │   ├── base.py
│   │   ├── mock_lesion.py      # mock 病灶检测
│   │   └── mock_llm.py         # mock LLM
│   └── repositories/
│       ├── __init__.py
│       └── knowledge_base.py   # 知识库数据访问
├── data/
│   ├── knowledge_base.jsonl    # 示例知识库
│   └── samples/                # 示例 DICOM（说明）
├── tests/
│   ├── test_pipeline.py
│   └── test_retriever.py
└── scripts/
    ├── build_index.py
    └── run_demo.py
```

>说明：本方案方法步骤按 S1–S8 编号，权要编号按步骤顺序映射：权要1=完整流程 S1–S8；权要2=影像获取与病灶信息确定（S1–S2）；权要3=病灶检索数据生成（S3）；权要4=关键词+语义向量双路检索（S4）；权要5=可信度筛选（S5）；权要6=分析结果生成（S6，含病灶类型/状态评估/诊断依据）；权要7=分析报告生成（S7，含三视图与合规校验）；权要8=报告推送与闭环迭代（S8）。
